# NVC Studio — FAQ

## Начало работы

**Что такое NVC Studio?**
Локальная веб-консоль для NVC — набора инструментов для конверсии голоса. Здесь собраны инференс, разделение дорожек, библиотека моделей, обучение и работа с чекпоинтами на одной странице, которая открывается прямо в браузере. Всё работает на вашем компьютере — аудио никуда не уходит, кроме случаев, когда вы импортируете модель по ссылке.

**Куда класть модели голосов?**
Положите файлы `.pth` в папку `assets/weights` и нажмите **Обновить список** на странице инференса. Индексы (`.index`) подхватываются автоматически из `logs/`.

## Инференс

**Зачем нужен индекс?**
Обученный Faiss-индекс добавляет в результат тембр по ближайшим известным фрагментам аудио — модель ищет похожие кусочки и подмешивает их. **Доля индекса** управляет силой эффекта: 0 — выключен, 1 — применяется на полную. Полезно, чтобы сохранить характер целевого голоса на долгих нотах.

**Какой метод высоты выбрать?**
`rmvpe` — по умолчанию, хорошо подходит для вокала. `fcpe` быстрее и хорош для речи. `pm` — лёгкий запасной вариант, если остальные сбосят.

**Что делают «Смешение огибающей» и «Защита согласных»?**
Смешение огибающей переносит громкость исходника в результат — чем выше значение, тем ближе динамика к оригиналу. Защита согласных не даёт глухим согласным (с, т, к, …) искажаться от индекса и сдвига высоты.

**Что значит транспонирование?**
Полутоны. `+12` — октава вверх, `-12` — октава вниз. Подбирайте так, чтобы источник попал в удобный диапазон целевого голоса.

## Разделение

**Что делает страница «Разделение»?**
Раскладывает аудио на две дорожки встроенными моделями pymss: вокал/минус, убирание реверберации или выделение основного вокала. «Агрессивные» варианты режут сильнее, но могут стоить качества.

## Обучение

**Какой порядок действий?**
1. Страница обучения — задайте имя эксперимента, частоту и версию.
2. Шаг 2a — нарезка и нормализация папки с данными или перетащенного `.zip`.
3. Шаг 2b — извлечение признаков HuBERT и высоты.
4. Шаг 3 — обучение модели, затем обучение индекса.

**Сколько нужно данных?**
10–30 минут чистой записи одного спикера — нормальный старт. Больше — лучше, но шумные записи вредят сильнее, чем меньший объём чистых.

**Мультиспикерное обучение?**
Выберите тип набора «Несколько спикеров» и либо назовите подпапки `Name_ID_Repeat` (ID 0–109), либо отправьте манифест на странице «Спикеры».

## Библиотека и чекпоинты

**Что можно импортировать?**
Архивы моделей (`.zip`) с устройства или по ссылке (Drive, Mega, Яндекс, MediaFire, Hugging Face), а также пары претрейнов v2 G/D для дообучения.

**Зачем нужны инструменты чекпоинтов?**
Сливать две модели с весом, править встроенную информацию модели, смотреть метаданные чекпоинта и доставать малую модель для инференса из тренировочного чекпоинта.

## Проблемы

**В строке устройства указан CPU.**
CUDA не обнаружена. Установите PyTorch с CUDA из подходящего файла `requirments_cu*.txt`.

**Конвертация падает с ошибкой индекса.**
Выбранный `.index` не подходит модели или отсутствует. Выберите «Не использовать индекс» или обучите индекс заново для этого голоса.
