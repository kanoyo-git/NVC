Step 3 · Train model and index

        

          
          
          
          

            Save only latest ckpt
            
            
          

          

            Cache set in VRAM
            
            
          

          

            Save small model each checkpoint
            
            
          

          

            Multi-scale mel loss?Mel-L1 over multiple window lengths. Slightly improves synthesis quality, training ~5% slower. F0 models only. Ported from Applio.
            
            
          

          

            Gradient checkpointing?Recompute activations during backward instead of storing them. Cuts VRAM (larger batch on 8GB cards), training ~15–20% slower. F0 models only. Ported from Applio.
            
            
          

          

            BF16 mixed precision?BFloat16 is more stable than FP16 on Ampere+ GPUs, needs no GradScaler, pairs with AnyPrecisionAdamW (Kahan summation) for FP32-grade quality. Falls back automatically when unsupported. Ported from Applio.
